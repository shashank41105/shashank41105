### About

CSE student at **Nalla Narasimha Reddy Education Society's Group of Institutions, Hyderabad (2023–2027)**. I design production-shaped AI systems: stateful multi-agent graphs, retrieval pipelines, and Slack-native tools that actually take action — not just generate text.

I care about the unglamorous parts that make agents usable: approval gates, allowlists, fallbacks across model providers, and deterministic quality checks around the LLM.

- **Building now:** [ChaosMind](https://github.com/shashank41105/ChaosMind) — a LangGraph chaos-engineering loop that hypothesizes failures, injects faults in Docker, judges the blast, then opens a GitHub PR with a patch.
- **Focus:** agent orchestration, RAG, local inference, FastAPI backends, and reliability automation for DevOps / SRE workflows.
- **Open to:** internships and build-heavy roles in AI systems, agent platforms, and applied LLM engineering.
